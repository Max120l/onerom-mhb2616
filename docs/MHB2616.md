# The Tesla MHB 2616

What is known about this chip, and — since the PMD 85-3 CPU board schematic
(DOSKA CPU, 1 PK 280 77) arrived — what is *measured* about how the machine
uses it. The two are kept separate on purpose: the schematic settles how the
board must behave in this machine, without claiming to be a datasheet for
the silicon.

## Known about the part

- **2048 × 8, 24-pin, 5 V read operation.** Every reference that mentions the
  MHB 2616 places it beside the MHB 2716 as the 2 KB generation of Tesla
  memory parts, used in PMD 85 monitor sockets alongside the Soviet К573РФ5.
- **It is the PROM, 2716 the EPROM.** The x616/x716 naming split (also seen
  as MMN2616/MMN2716 from Microelectronica) is programmable-once versus
  UV-erasable. Surveyed PMD 85-3 units carry 2616s labelled only with paper
  stickers — consistent with factory-programmed OTP parts.
- **Address, data and power pins follow JEDEC 2716.** A0–A10 on pins 1–8,
  19, 22, 23; D0–D7 on 9–17; GND 12, Vcc 24.
- **Timing is generous.** Parts of this class are 350–450 ns; the PMD 85's
  8080 runs at ~2 MHz. Nothing in this project is timing-critical the way
  the 1801RE2's handshake was.

## Measured: the control pins, per the PMD 85-3 schematic

This is where the 2616 parts company with the JEDEC 2716, and it is read
off the schematic rather than inferred:

| pin | 2716 has | PMD 85-3 wires it as |
|-----|----------|----------------------|
| 18 | /CE | **PR** — fed A11 (DS4, DS6) or inverted A11 (DS5, DS7) |
| 20 | /OE | **/CS** — active-low pair select, DS4+DS5 tied, DS6+DS7 tied |
| 21 | Vpp | **+5 V**, strapped to the rail with pin 24 |

So the chip has *two* select inputs where a 2716 has enable+output-enable,
and the machine uses one as a genuine select (/CS, from the address decoder)
and the other as an address bit in select's clothing (PR ← A11). Pin 21
carries nothing.

**PR is active low — settled.** The Infoserver archive's per-chip files
place chip E (socket DS4) at monitor offset 0: bank 0, selected when
A11 = 0 — and DS4's PR is straight A11, so the chip answers with PR held
low. The inverted sockets agree. This also closes the loop on why MHB
2716 substitutions worked: a 2716 in these sockets sees /CE ←
A11-or-its-inverse and /OE ← the pair select, both active low, both
required — precisely the 2616's behaviour under this wiring. The
firmware's `MHB_PR_INVERT` switch remains a pure socket property (ON for
DS5/DS7): the board's bank bit is A11 itself, regardless of the chip's
select sense. Full per-socket table: [PMD85-3.md](PMD85-3.md).

**If a real MHB 2616 datasheet surfaces** (Tesla catalogue sheets do
circulate — MHB 4116, MHB 8080A, MHB 1012 are all online), it would be a
welcome cross-check but no longer gates anything. Likely sources: KONDIK
and soucastka component catalogues, scanned Amatérské radio annuals,
SAPI.cz.

## In the PMD 85-3

Four sockets, 8 KB of monitor, one 2 KB window each:

| bank | monitor offset | A12 (pair select) | A11 (PR) |
|------|----------------|-------------------|----------|
| 0 | 0x0000–0x07FF | 0 | 0 |
| 1 | 0x0800–0x0FFF | 0 | 1 |
| 2 | 0x1000–0x17FF | 1 | 0 |
| 3 | 0x1800–0x1FFF | 1 | 1 |

`tools/gen_rom_images.py --monitor` splits a flat 8 KB image (the
`monit3B.rom` shape) in exactly this order. The socket assignment is now
settled byte-for-byte from the Infoserver archive's per-chip files:
DS4 "E" = bank 0 through DS7 "B" = bank 3, letters descending as
addresses ascend — "in order E-D-C-B from the microprocessor", as the
archive's own notes put it. (The schematic prints DS6's letter as "0"; the
real machine says C — one of the sheet's typos.) The full table with build
switches per socket: [PMD85-3.md](PMD85-3.md).
